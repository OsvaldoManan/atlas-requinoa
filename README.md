# Atlas Electoral Requínoa

Sitio con el análisis de las elecciones municipales de Requínoa (Región de O'Higgins, Chile) entre 1992 y 2024 y simuladores de escenarios para la alcaldía y el concejo 2028.

Datos: SERVEL, TRICEL e INE. Los escenarios son simulaciones con supuestos explícitos, no pronósticos.
