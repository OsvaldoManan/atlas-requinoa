# Atlas Electoral Requínoa

Sitio con el análisis de las elecciones municipales de Requínoa (Región de O'Higgins, Chile) entre 1992 y 2024, simuladores de escenarios para la alcaldía y el concejo 2028, recomendaciones políticas por sector y la metodología.

**Autoría:** Osvaldo Mañán Arce  
Administrador Público y Licenciado en Ciencia Política, Universidad de Talca  
Doctorado (c) en Procesos e Instituciones Políticas, Universidad Adolfo Ibáñez

Datos: SERVEL, TRICEL e INE. Los escenarios son simulaciones con supuestos explícitos, no pronósticos.
